# Source Map — IEC 60364-5-52:2009 Ed. 3.0

## Status

- Source reviewed: `IEC 60364-5-52:2009`, Edition 3.0
- Subject: selection and erection of wiring systems in low-voltage installations
- V0 relevance: **high**
- Current-edition status for this project: **base edition available, Amendment 1:2024 not yet reviewed**
- Verification state: rules may be mapped to this edition, but any claim of **current IEC verification** must wait until the 2024 amendment is checked for changes affecting that rule.

This file is a paraphrased index only. It does not reproduce IEC tables or substantial copyrighted text.

## What this standard can support in V0

### 1. Installation-method selection

**References:** Clauses 521.1–521.3; Annex A, especially Tables A.52.1–A.52.3.

Use in the checker:
- classify the cable/conductor arrangement;
- map the real installation to an IEC reference installation method;
- use that reference method to select the correct current-carrying-capacity dataset.

Required inputs:
- cable/conductor type;
- single-core or multi-core arrangement;
- location/installation situation;
- enclosure, conduit, tray, ladder, wall, ground, free-air or comparable installation information.

Important limitation: the software must not choose an installation method from cable size alone.

### 2. Base current-carrying capacity (`Iz`)

**References:** Clause 523.1; 523.2; 523.3; Table 52.1; Annex B.

Mapped logic:
- conductor current during sustained normal operation is limited by the permitted operating temperature of the insulation/system;
- 523.2 permits selection from the Annex B current-carrying-capacity tables, referenced through the installation-method mapping in Annex A, with applicable correction factors;
- 523.3 also allows a value determined using the IEC 60287 series, testing, or another recognized calculation method when the method is stated.

Relevant base table families in Annex B include combinations of:
- PVC versus XLPE/EPR insulation;
- two versus three loaded conductors;
- copper versus aluminium;
- reference installation methods including buried, enclosed and free-air arrangements.

V0 rule: `Iz` is not a single property of a conductor cross-section. It is the outcome of cable construction + loaded-conductor count + installation method + reference conditions + correction factors.

### 3. Ambient-temperature correction

**References:** 523.4; Table B.52.14 for air; Table B.52.15 for ground.

Use in the checker:
- apply a correction when actual ambient air temperature differs from the reference air temperature used by the selected base table;
- apply the appropriate ground-temperature correction for buried/ducted cases when relevant.

V0 must retain both the base-table reference temperature and the actual design temperature in the trace.

### 4. Soil thermal conditions

**References:** 523.3; Table B.52.16 and the applicable buried-cable table family.

Use in the checker:
- buried-cable ampacity may require correction where soil thermal resistivity differs from the reference condition.

Required input when applicable:
- burial method;
- soil thermal resistivity or an explicitly verified project/design value.

No default should be silently assumed for an unknown site condition.

### 5. Grouping / multiple circuits

**References:** 523.5; Tables B.52.17–B.52.21.

Mapped logic:
- grouping reduction depends on the arrangement and reference method;
- groups containing cables with differing maximum operating temperatures need special handling based on the lowest applicable temperature limit plus the appropriate group factor;
- the clause includes a limited condition under which a lightly loaded cable may be disregarded for grouping-factor determination.

V0 inputs will therefore need more than `number_of_cables`; they need enough arrangement information to select the relevant grouping table/rule.

### 6. Number of loaded conductors and harmonics

**References:** 523.6; Annex E.

Mapped logic:
- ampacity depends on the number of conductors actually carrying load current;
- in a balanced polyphase circuit the neutral may, under the specified conditions, be excluded from the loaded-conductor count;
- significant triplen harmonic current changes the treatment of the neutral and can require additional thermal consideration;
- Annex E contains harmonic-related reduction guidance.

V0 implication: the input model should include:
- number of phases;
- neutral present/not present;
- neutral loading basis;
- harmonic status where relevant.

A simple `3-phase = 3 loaded conductors` assumption is not universally safe.

### 7. Parallel conductors

**References:** 523.7; Annex H (examples/configurations).

Mapped logic:
- parallel live/PEN conductors require measures that achieve suitable current sharing;
- the standard identifies characteristics relevant to equal sharing, including matching conductor material, cross-section and approximately equal length, plus arrangement requirements;
- when adequate sharing cannot be achieved, a simple equal split must not be assumed;
- special consideration is called for in larger parallel arrangements.

V0 inputs should therefore eventually include:
- number of parallel runs;
- same/different material;
- same/different cross-section;
- length equality/tolerance;
- cable/core configuration;
- physical arrangement where required.

The tool must not calculate `Iz_total = number_of_runs × Iz_single` unless the applicable current-sharing and grouping conditions have been verified.

### 8. Changes in installation conditions along a route

**Reference:** 523.8.

Mapped logic:
- where heat dissipation changes along the route, ampacity is normally governed by the most adverse relevant section.

V0 implication:
- one feeder may need multiple route segments;
- a later V0.x/V1 input model should support segment-level installation conditions instead of one global installation method.

For the first implementation, a single installation method may be supported only with an explicit limitation stating that the user must enter the governing/worst-case condition.

### 9. Voltage drop

**References:** Clause 525; Annex G; Table G.52.1.

Mapped logic:
- Clause 525 directs consideration of voltage drop from the origin of the consumer installation to the equipment;
- Annex G provides informative guidance and a table for the voltage-drop criterion/methodology in this edition;
- motor starting and high-inrush equipment can require additional consideration beyond a steady-state percentage check.

V0 should keep separate:
- calculated voltage drop;
- selected permitted limit;
- source of that limit (IEC guidance, national rule, client/project criterion, or other verified source).

Because Annex G is informative, the checker must not present every value from it as a universal mandatory IEC requirement without considering applicability and national/project rules.

## Proposed V0 `Iz` data flow

```text
cable construction
+ conductor material
+ cross-section
+ insulation / permitted temperature
+ loaded conductors
+ installation method
        ↓
reference Iz
        ↓
ambient / ground correction
× soil correction (if applicable)
× grouping correction
× harmonic correction (if applicable)
        ↓
corrected Iz
        ↓
parallel-run validation / sharing logic
        ↓
usable circuit Iz
```

Every stage should retain its source reference and factor in the calculation trace.

## Inputs now known to be necessary for the cable module

At minimum:

- conductor material;
- conductor cross-sectional area;
- insulation/cable thermal class or a mapped cable family;
- single-core/multi-core construction;
- number of loaded conductors;
- installation/reference method;
- ambient air temperature or buried-ground temperature, as applicable;
- grouping arrangement / number of relevant circuits;
- burial and soil thermal-resistivity data where applicable;
- parallel-run count and current-sharing applicability;
- harmonic/neutral-loading status where relevant.

Optional/future inputs include segmented route conditions and additional manufacturer-specific thermal constraints.

## Known gaps before current-edition verification

1. **IEC 60364-5-52:2009/AMD1:2024 has not yet been reviewed.** Any affected mapping remains base-edition verified only.
2. **IEC 60364-4-43 current edition is not available in the project library.** `In`/overcurrent-protection compliance cannot yet be promoted to current-IEC VERIFIED.
3. Some cable families in the private reference cases, particularly fire-performance cable constructions, may require manufacturer/product data or another recognized current-rating method rather than assuming an Annex B table is directly applicable.
4. National/local requirements may modify or supplement IEC guidance and must be modeled separately rather than silently folded into the IEC layer.

## Implementation rule

No table value should be copied into source code without:

- a defined legal/data-source approach;
- table/edition traceability;
- explicit applicability fields;
- regression tests;
- a way to mark the dataset superseded when an amendment or later edition changes the basis.
