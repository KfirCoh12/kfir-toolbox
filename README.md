# Kfir Toolbox

A private collection of reviewed, tested, and customized tools for work and personal use.

## Purpose

This repository is a controlled toolbox—not a dump of downloaded projects. Each added tool should solve a clear problem, have a traceable source, and be reviewed before use.

## Categories

- [Revit & BIM](revit-bim/README.md) — Revit, Dynamo, pyRevit, model inspection, and BIM utilities.
- [Electrical Engineering](electrical-engineering/README.md) — calculation tools, data checks, and engineering utilities.
- [Windows & Productivity](windows-productivity/README.md) — useful desktop automation and quality-of-life tools.
- [Experiments](experiments/README.md) — unproven ideas and prototypes that are not ready for normal use.

## Tool status

Each tool should be marked with one of these states:

- **Candidate** — found, but not fully reviewed.
- **Reviewed** — source, license, compatibility, and risks checked.
- **Testing** — being tested with safe sample data.
- **Approved** — suitable for intended use.
- **Archived** — retained for reference but no longer recommended.

## Safety rules

1. Never test an unfamiliar tool on the only copy of a Revit model, document, or dataset.
2. Do not commit passwords, API keys, seed phrases, company documents, or confidential project data.
3. Confirm the license before copying or modifying third-party code.
4. Record the original repository and version or commit.
5. Check Revit, Dynamo, Python, .NET, and Windows compatibility where relevant.
6. Prefer a small, understandable adaptation over importing an entire project unnecessarily.
7. Work-related tools require employer approval before installation or use on company systems.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the review template and workflow.
